# And Défar Fass Noflaye — site web

Site de présentation de l'initiative communautaire d'assainissement, d'éclairage et de développement à Fass Noflaye – Rufisque.

Site statique (HTML + CSS) publié avec GitHub Pages : https://babacar97.github.io/siteWebFassNoflaye/

## Structure

- `index.html` : la page unique du site
- `style.css` : styles
- `img/` : images (format WebP pour être légères), logo, QR codes de contribution
- `video/` : `fond-banniere.mp4` (boucle de la bannière) et `presentation.mp4` (vidéo de présentation)

## À compléter / modifier

- Chiffres de la section « Fass en chiffres » : repérer le commentaire `CHIFFRES PROVISOIRES` dans `index.html`.
- Réseaux sociaux : repérer le commentaire `À AJOUTER` dans le pied de page.
- Titulaire du compte Wave / Orange Money : repérer le commentaire `À COMPLÉTER` dans la fenêtre de contribution.
- Section « Membres de l'équipe » : bloc commenté dans `index.html`, à réactiver quand les photos et noms sont validés.

## Conseil pour les nouvelles images et vidéos

Les compresser avant de les ajouter (images en WebP ou JPEG < 300 Ko, vidéos en MP4 H.264 < 15 Mo) et utiliser des noms de fichiers sans espaces ni accents.
